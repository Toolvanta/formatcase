FormatCase — Online Case Converter & Developer Text Utilities

Free, instant, 100% private in-browser case formatter. Convert strings between camelCase, snake_case, kebab-case, PascalCase, Title Case, and 25+ formats with zero latency.

Supported Casing Formats & Conventions

camelCase

helloWorld • JavaScript, TypeScript, Java, Swift

First word is lowercase, and every following word starts with a capital letter.

PascalCase

HelloWorld • React, C#, TypeScript types

Every single word starts with a capital letter, with no spaces in between.

snake_case

hello_world • Python, SQL databases, Rust

All characters are lowercase, with words joined together by underscores.

kebab-case

hello-world • URLs, CSS classes, HTML tags

All lowercase letters joined by hyphens. Clean and easy to read in URLs.

SCREAMING_SNAKE_CASE

HELLO_WORLD • .env files, constants

All uppercase letters connected with underscores for constants.

Title Case

Hello World • Headlines, blog titles, articles

Capitalizes major words like a book title, keeping minor words lowercase.

Frequently Asked Questions (FAQ)

Why are there so many different casing styles anyway?

Most programming languages and computer systems don't allow spaces in variable names, database columns, or URLs. Different communities settled on conventions: JavaScript uses camelCase, Python uses snake_case, and URLs adopt kebab-case.

What is the difference between camelCase and PascalCase?

With camelCase, you start with a lowercase letter (e.g., userProfile). With PascalCase, you capitalize from the very beginning (e.g., UserProfile).

Is my text private? Does anything get sent over the internet?

Zero. Nothing leaves your device. FormatCase runs 100% inside your web browser memory without remote servers or tracking.
